# FACELESS 2 — made by zorix

A new surveillance-horror sequel-style project built in Godot 4 for Android landscape play.

Core systems:
- story / rush / nightmare / exploration / blackout modes
- first-person movement, sprint and crouch
- flashlight battery
- Faceless chase AI
- three randomized relay objectives
- evidence collection
- security-camera terminal
- checkpoint save / continue
- mobile joystick and large action buttons
- graphical settings and accessibility toggles
- real imported GLB asset instances generated at build time
